# Typing benchmark data

Used by `TypingBenchmarkTest`. Not shipped in the app.

`sentences_en.txt` is generated by [`make_bench.py`](../make_bench.py) in the
Dictionary workflow and committed here.

The misspellings list is **not stored in this repo**: it is share-alike
(CC BY-SA 4.0), and the repo is Apache-2.0. The Build workflow downloads it to
`tools/bench/cache/` (git-ignored) before the tests. To run that part of the
benchmark yourself:

```sh
python3 tools/bench/make_bench.py --misspellings
```

Without it, the misspellings part of the benchmark is skipped and the rest
still runs. The list is fetched from the live page, so it can change slightly
between downloads; CI keeps one copy cached to keep scores comparable.
