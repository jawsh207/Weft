**Weft 0.1.0 — the first release**

### New
- Material 3 Expressive keyboard that takes its colors, dark mode, contrast and font from your system theme
- Swipe typing: draw across the letters and Weft finds the word, with a live preview and alternatives in the suggestion strip
- Suggestions, typo correction and next-word predictions from a 150,000-word English dictionary; delete right after an autocorrect to undo it
- Splits run-together words ("letgo" → "let go") and fixes common contractions ("im" → "I'm")
- Learns your words on the device only, never in password or incognito fields; clear them any time in settings
- Emoji picker in your phone's own emoji font, with recents, skin tones and search by name, keyword or shortcode
- Voice input through whichever speech engine you've chosen in system settings
- Long-press alternates for accented letters, punctuation, superscripts and fractions
- Slide along the space bar to move the cursor
- Symbols pages and a phone-style number pad, which opens on its own in number fields

### Install note
- If you installed a test build from GitHub Actions, uninstall it first: release builds are signed with a different key. Then turn Weft back on in the setup screen.
