**Weft 1.1.0 — editing keys, landscape, and a taller default**

### New
- The tools row has Select all, Cut and Copy beside Paste, Clear clipboard and Settings. The buttons are icons now, so all six fit
- Key height has four choices: Mini, Compact, Normal and Tall. Normal is one step taller than before, and Tall is new
- In landscape on a phone, the keys shrink so the keyboard takes about half the screen
- Settings › About › Troubleshooting: a short log of when the keyboard was asked to open and whether it did, to help find occasional problems. It never records what you type and stays on your phone unless you copy it

### Fixed
- The keyboard could be slow to open, or seem not to open, while an app was busy (a web page still loading, for example). It now appears first and reads the field afterwards
- In landscape, the keyboard no longer replaces the app with a full-screen text box, and no longer ignores an app's request to open
- Settings › About now names the dictionary's allow list and its license

### Install note
- If you never changed the key height, the keyboard will be a little taller after updating. Choose Compact in Settings › Keys to get the old size back. A height you had picked keeps its size under its new name
